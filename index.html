Battery Intelligence

Secure Platform for LEV Fleet Management

In partnership with Worthless.Dev, our Secure Battery Intelligence Platform represents custom hardware development and a vertically integrated data ecosystem tailored for the high-performance, long-range Light Electric Vehicle (LEV) sector.

The platform facilitates the translation of raw battery-cell data into actionable cloud analytics, supporting:

  • Battery-as-a-Service (BaaS) rental and leasing-to-own strategies
  • Technical assurance for fleet administration
  • Battery leasing initiatives

Core Technical Innovations

Data Translation Layer

RAC is developing a proprietary hardware and software stack to translate disparate data streams into a unified telemetry format.

  • Multi-Protocol Support: Compatible with JBD, ANT, and JK Battery Management Systems (BMS)
  • Seamless Monitoring: Enables diverse fleet assets to communicate with a central server
  • Standardized Protocol: Ensures various hardware brands operate through a unified interface

Cellular-Edge Telemetry

Battery units incorporate tamper-proof, dedicated low-power cellular communication modules for real-time data transmission.

  • Key Metrics: State of Charge, State of Health, and Thermal Profiles
  • Always-On Connectivity: Eliminates manual Bluetooth synchronization
  • Proactive Management: Enables predictive battery safety monitoring and fleet management

Predictive Health Monitoring & Smart Alerts

RAC is developing a backend monitoring platform with sophisticated filtering capabilities.

  • Intelligent Filtering: Eliminates false "Critical" and "Warning" alerts from transient electrical noise
  • Actionable Alerts: Notifies operators only of actual safety concerns or performance issues
  • Scalable Operations: Efficiently manage hundreds of leased assets with reduced technical burden

Smart Display & Command Module

Product Design for Light Electric Vehicles

Rise Above Consulting is providing product design, testing, and go-to-market support for a display and command module designed for custom light electric vehicles.

In a market where no off-the-shelf solution exists, Worthless.Dev created a device many in the electric vehicle community have been dreaming of for years. Given the opportunity, Rise Above Consulting partnered with Worthless.Dev to refine, validate, and prepare this advanced command display for production. The module centralizes vehicle status monitoring and enables intuitive control of core vehicle functions.

This project represents a close technical and strategic collaboration between Rise Above Consulting and Worthless.Dev to bring a purpose-built solution to an emerging EV segment.
